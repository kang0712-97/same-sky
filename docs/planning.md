# Same Sky (같은 하늘) — 서비스 기획 정리

## 1. 서비스 콘셉트

서로 다른 하늘 아래, 하나의 하루를 함께하는 공간.

장거리 연애 커플을 위한 일상 공유 서비스. 서로 다른 나라에 있어도 상대방의 날씨, 시간, 달의 모습을 확인하고 하루의 소중한 순간을 공유할 수 있다.

일반적인 메신저처럼 끊임없이 연락하는 것이 아니라, 하루에 단 세 번의 사진을 통해 서로의 일상을 연결한다.

## 2. 핵심 기능

### ① 우리의 두 하늘
- 두 사람의 도시별 현재 날씨와 기온
- 각 도시의 현지 시간과 시차
- 일출 및 일몰 시간
- 오늘의 달 모양(초승달, 반달, 보름달 등)
- 월출 및 월몰 시간
- 날씨와 시간에 따라 달라지는 시각적 배경
- 두 사람이 동시에 달을 관측할 수 있는 시간 안내(추후 확장)

### ② 오늘의 3장
- 사용자마다 하루 최대 3번 사진 촬영 및 업로드 가능
- 기본적으로 앱 내 카메라로 촬영
- 사진 1장당 짧은 메시지 작성 가능
- 촬영 시각과 해당 도시의 날씨 자동 기록
- 사진에 당시 달 정보도 함께 표시 가능
- 업로드한 사진은 상대방에게 공유
- 상대방은 하트 등 간단한 반응 가능
- 하루가 지나면 업로드 횟수 초기화
- 사진은 커플 전용 앨범에 보관

사진은 아침·점심·저녁으로 구분하지 않고 원하는 시간에 자유롭게 올리되 하루 최대 3회로 제한하는 방식도 고려할 수 있다.

### ③ 우리 둘만의 시간
- 서로의 현지 시간 실시간 확인
- 시차 시각화
- 각자의 활동 가능 시간 설정
- 두 사람이 함께 통화하거나 시간을 보낼 수 있는 구간 추천

### ④ 우리의 하늘 기록
- 날짜별로 서로 공유한 사진 확인
- 사진을 찍었을 당시의 날씨와 시간 기록
- 두 사람의 하루를 나란히 비교
- 지난 추억을 볼 수 있는 커플 전용 아카이브

## 3. 추후 확장 기능

- 날씨 편지: 상대방의 도시에 비가 오거나 눈이 내리면 미리 작성한 편지 전달
- 같은 달 보기: 두 사람이 달을 관측할 수 있는 공통 시간 안내
- 원격 데이트: 날씨와 시차를 고려한 온라인 데이트 추천
- 다시 만나는 날: 다음 만남 D-day 및 양국 공휴일 비교
- 특별한 하늘: 보름달, 첫눈, 일출 등 특별한 순간의 알림

## 4. 활용 API

| API | 활용 목적 |
| --- | --- |
| Open-Meteo Weather | 전 세계 도시의 날씨, 기온, 구름량, 일출·일몰 |
| Open-Meteo Geocoding | 도시 검색, 좌표 및 시간대 |
| 천문 계산 라이브러리 또는 천문 API | 달의 위상, 월출·월몰, 관측 가능 시간 |
| Nager.Date | 국가별 공휴일 정보 |
| Supabase | 커플 연결, 사진·메시지 저장, 계정 관리 |

날씨와 천문정보는 공개 API 또는 계산 라이브러리로 구현할 수 있으며, 사진과 메시지 공유에는 별도 백엔드가 필요하다.

## 5. MVP 제안

1. 커플 연결 및 각자의 도시 설정
2. 두 도시의 날씨·시간·달 정보 표시
3. 하루 최대 3회 사진 촬영 및 공유
4. 사진에 짧은 메시지 첨부
5. 상대방 사진 확인 및 하트 반응
6. 날짜별 커플 사진 기록
7. 현지 날짜 기준 업로드 횟수 초기화

## 6. 핵심 차별점

- 일반 메신저: 언제든 무제한으로 소통하는 공간
- 일반 커플 앱: 기념일, 일정, 사진 등을 관리하는 공간
- Same Sky: 서로의 하늘과 시간을 느끼며, 하루에 가장 전하고 싶은 세 순간을 공유하는 공간

## 7. 핵심 사용자 경험

- 연결감: 떨어져 있어도 서로의 하루를 가까이 느낀다.
- 기다림: 상대방이 어떤 순간을 보내줄지 기대한다.
- 특별함: 무제한이 아닌 하루 3번의 공유로 순간에 의미를 부여한다.
- 기록: 시간이 흐르면 두 사람이 서로 다른 장소에서 보낸 날들이 하나의 앨범으로 남는다.

## 8. 서비스 핵심 문장

> Same Sky — 다른 곳에 있어도, 같은 하늘 아래.
>
> 하루에 단 세 번, 너에게 보여주고 싶은 나의 순간.
>
> 서로 다른 날씨와 시간을 살아가지만, 우리는 서로의 하루를 함께한다.
